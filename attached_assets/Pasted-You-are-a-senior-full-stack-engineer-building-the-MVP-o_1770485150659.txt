You are a senior full-stack engineer building the MVP of a startup application called MyGrid.

MyGrid is a mobile-first and web-compatible platform that connects motorsports drivers with photographers and videographers attending specific events, allowing drivers to view portfolios and book media creators directly.

Your goal is to build a scalable, clean, and production-ready MVP foundation using modern best practices. DO NOT overbuild advanced features beyond the MVP requirements.

---------------------------------------
TECH STACK REQUIREMENTS
---------------------------------------

Frontend:
- React Native using Expo (mobile-first)
- Next.js for web compatibility
- TypeScript required
- Clean reusable component structure

Backend:
- Supabase (authentication + database + storage)
- Supabase real-time messaging
- Stripe integration placeholder (do not fully implement yet, only scaffold structure)

UI:
- Clean modern motorsports-inspired UI
- Dark theme default
- Responsive layout
- Use reusable UI components

Architecture:
- Modular folder structure
- Scalable service-based architecture
- Maintain clear separation between UI, logic, and data services

---------------------------------------
CORE USER ROLES
---------------------------------------

Two account types:

1. Driver
2. Media Creator (Photographer, Videographer, Drone, Social Content)

Users must select role during onboarding.

- id
