You are a senior product designer + mobile engineer working on MyGrid.

Goal: improve event-card readability and upgrade creator profiles so they feel more premium, trustworthy, and booking-focused.

------------------------------------------------------------
A) EVENT CARD HIERARCHY UPGRADE
------------------------------------------------------------

Improve the Events list card layout so users can scan events faster.

Required layout order:

1. Thumbnail/banner image
2. Event name — strongest visual element
3. Host line
4. Date line
5. Location line
6. Event type pill / featured pill if available

Design requirements:
- Event name should be bold, larger, and visually dominant.
- Limit event name to 2 lines max.
- Host line should be smaller and subtle:
  “Hosted by {host}”
- Date and location should be easy to read with small icons if available.
- Event type pill should be small and clean.
- Featured events should have a subtle “Featured” badge.
- Maintain dark premium motorsports style.
- Preserve current event click behavior.

Acceptance:
- Event name clearly stands out first.
- Cards look consistent with or without real banners.
- No event data logic is broken.

------------------------------------------------------------
B) CREATOR PROFILE PREMIUM UPGRADE
------------------------------------------------------------

Upgrade creator profiles so drivers instantly understand:
- who the creator is
- what they shoot
- where they’ll be
- what packages they offer
- how to book them

Profile layout should prioritize booking conversion.

Required creator profile structure:

1. Hero/Profile Header
- Large profile image/avatar
- Display name / brand name
- Creator tags: Photographer, Videographer, Drone, Social Content, etc.
- Location
- Short bio
- Message button
- Book Creator button if viewer is not the profile owner

2. Trust / Activity Summary Row
Show compact stats if data exists:
- Portfolio items count
- Events attending count
- Packages count
- Completed bookings count if available

If a stat is unavailable, hide it gracefully.

3. Availability / Upcoming Events Section
- Show upcoming events the creator is attending
- Include availability badge:
  Available / Limited / Fully Booked
- Make each event card clickable

4. Packages Section
- Display pricing packages as premium cards
- Package card should include:
  - Package title
  - Short description
  - Price
  - “Request Booking” button
- Request Booking should route into the existing booking flow with creator preselected where possible.

5. Portfolio Section
- Keep current photo/video portfolio grid
- Make it visually cleaner:
  - consistent spacing
  - rounded corners
  - thumbnail preview
  - external video cards should look intentional, not plain links

6. Empty States
If creator has no packages:
- Show: “No packages added yet.”

If creator has no portfolio:
- Show: “No portfolio added yet.”

If creator has no upcoming events:
- Show: “No upcoming events listed yet.”
